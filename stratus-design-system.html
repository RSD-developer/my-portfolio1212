Design system

Stratus

A restraint-first design language distilled from the structural DNA of apple.com/macbook-air — then stripped of brand, rebuilt on a three-layer token architecture, and made fluid so it lays out against any structure you throw at it.

12-step fluid type scale Sign-flipping tracking law 1 accent hue 4px spatial base Zero-shadow depth Dark mode via alias remap

Foundation

Six principles

Extracted from what the source page actually does, not from what it says. These are the load-bearing decisions — every token below is downstream of one of them.

1 · Scale is the only hierarchy

The source page uses one typeface, one weight for headings (600), and one chromatic hue. All emphasis is carried by size — an 80px hero sitting beside 17px body is a 4.7× jump. Nothing is bolded, colored, or boxed to make it matter. It matters because it is big.

2 · Copy density is inverted

The visually loudest element carries the fewest words. The hero is 9 words. The median content unit is a 15–30 word caption. The largest editorial paragraph on the entire page is 62 words. Air is not leftover space — it is the primary compositional material.

3 · Depth without shadow

Across the whole source page, zero box-shadows were measured on content. Separation comes from three tools only: a tonal surface shift (#fff → #f5f5f7), a hairline rule, and a generous corner radius. Shadows are reserved for genuinely floating UI.

4 · One measure, held ruthlessly

A single 980px container appeared 95 times. Everything — headlines, body, grids, stat rows — snaps to the same measure regardless of viewport. Full-bleed media is the only sanctioned escape. This is what makes long scrolling pages feel composed rather than assembled.

5 · Every claim is anchored

Every number on the source page carries a footnote marker — 26 numbered refs plus 4 symbol refs. The system treats the footnote as a first-class component, not an afterthought. Confidence in the display type is earned by rigor in the fine print.

6 · Motion reveals, never decorates

The dominant easing is cubic-bezier(.4, 0, .6, 1) — symmetrical, unhurried, no overshoot, no bounce. Animation exists to bring content into view on scroll and to soften state changes. It never draws attention to itself.

Token architecture

Three layers. Components only ever touch layer 2. That single constraint is what makes the system rebrandable in one file and themeable without touching a component.

LayerPrefixContainsWho reads it
1 · Primitive--p-*Raw hex, font stacks, the 4px base unit. No meaning attached.Layer 2 only. Never a component.
2 · Semantic--color-* --font-* --space-* --radius-*Intent-named aliases: --color-text-secondary, not --gray-500.Every component, every page.

Don't reference --p-neutral-500 from a component. If no semantic alias fits, create one — that's the signal you've found a genuine new intent.

Foundation

Typography

Twelve steps. Each ships size, line-height and tracking as one inseparable triple — mixing across steps is the fastest way to break the language.

The tracking law

The most distinctive and most-copied-wrong part of this language. Letter-spacing does not move monotonically with size — it flips sign twice. Large type is optically over-spaced by default, so it tightens. Mid-range display sizes are optically cramped, so they loosen. Text sizes tighten again for density. Get this wrong and the type reads as "default sans-serif" no matter how correct the sizes are.

ZoneSize rangeTrackingWhy
Display40 – 80px−0.015em → 0em (tightens as size grows)Counters optical over-spacing at large sizes
Title21 – 32px+0.004em → +0.011em (positive)Opens up the awkward mid-range so it doesn't clot
Text12 – 17px−0.022em → −0.01em (negative again)Increases density and word-shape at reading sizes

Foundation

Motion

Four curves, five durations. No bounce, no overshoot, no spring. Motion in this language brings content in and softens state — it is never the point.

TokenCurve / valueUse
--ease-standardcubic-bezier(.4, 0, .6, 1)Default. Hover, color, opacity, everything UI
--ease-inoutcubic-bezier(.42, 0, .58, 1)Symmetrical transforms, carousels
--ease-decelcubic-bezier(.25, .1, .3, 1)Entrances — fast in, slow settle
--ease-springcubic-bezier(.28, .11, .32, 1)Scroll-linked reveals
--dur-instant / fast100ms / 200msColor, opacity, micro-feedback
--dur-base300msDefault for transform and layout
--dur-slow500msPanel open, accordion, tab swap
--dur-reveal800msScroll-triggered content reveal

The scroll reveal

The only signature animation in the system. Content enters from translateY(28px) and opacity: 0 over 800ms on --ease-decel, staggered ~80ms between siblings. Everything below this line uses it — scroll and watch.

OneEnters first.
Two80ms behind.
Three160ms behind.
Do honour prefers-reduced-motion. The base reset already kills all durations to 0.01ms — don't override it.
Don't animate more than opacity and transform. Anything else drops frames and, in this language, calls attention to itself.

Using it

Rebranding in five values

Because components only read the semantic layer, retargeting the entire system to a different brand is a single block of CSS.

/* Drop this after the system stylesheet. Nothing else changes. */
:root {
  /* 1 — the accent ramp (the whole brand identity lives here) */
  --p-accent-300: #a78bfa;
  --p-accent-400: #8b5cf6;
  --p-accent-500: #7c3aed;   /* button fill  */
  --p-accent-600: #6d28d9;   /* link text — must clear 4.5:1 on white */
  --p-accent-700: #5b21b6;

  /* 2 — the type face (keep the metric-compatible fallback stack) */
  --p-font-display: "Outfit", -apple-system, "Helvetica Neue", sans-serif;
  --p-font-text:    "Outfit", -apple-system, "Helvetica Neue", sans-serif;

  /* 3 — optional: warm or cool the neutral ramp by a few degrees */
  --p-neutral-50:  #f7f5f9;
  --p-neutral-900: #1f1b24;

  /* 4 — optional: change the shape language wholesale */
  --radius-xl: 16px;      /* softer, more "product" than "marketing" */

  /* 5 — optional: change the rhythm */
  --section-y-md: clamp(48px, 6vw, 88px);   /* denser page */
}
KeepThe type scale ratios and the tracking law. These carry most of the perceived quality and are entirely brand-neutral.
TuneRadius and section rhythm. Tighter radius plus denser rhythm turns a marketing language into a product-UI language.
ReplaceThe accent ramp and the typeface. Everything else is intentionally generic so it survives the swap.

Using it

The ten rules

If a build only follows ten things, these are the ten.

  1. One typeface. One accent hue. Headings are always weight 600.
  2. Never set a font-size without its paired line-height and tracking. Use the .t-* classes.
  3. Body text is 17px and never scales. Only display and title steps are fluid.
  4. Snap to the 980px container unless the content is genuinely full-bleed media.
  5. Every spatial value is a --space-* token. No arbitrary pixels.
  6. Vertical section air comes from --section-y-*, never hand-written padding.
  7. Separate surfaces with tone and radius. Reach for a shadow only when something truly floats.
  8. One filled button per view. Everything else is a text link.
  9. Every number carries a footnote marker.
  10. Animate opacity and transform only, on --ease-standard, and respect reduced-motion.
